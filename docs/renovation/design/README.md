# 画面デザイン（Claude Design の書き出し）

改修後の画面の見た目の基準。各 `.dc.html` は Claude Design のアートボードで、`<x-dc>` の中が画面のマークアップ、末尾の `<script type="text/x-dc">` の `renderVals()` が表示用のサンプルデータと計算。**実装ではマークアップの構造・余白・色・文字サイズを参考にし、データは実際のAPIから取る。** サンプル値（指数・財務指標・ニュース見出しの［ ］など）はそのまま使わない。

| ファイル | 画面 |
| --- | --- |
| `Main.dc.html` | ホーム |
| `Holdings.dc.html` | 保有銘柄（15列＋右ペイン） |
| `Watchlist.dc.html` | 登録銘柄（19列・5タブ・トレードアイデア） |
| `Detail.dc.html` | 銘柄詳細（ローソク足チャート） |
| `Market.dc.html` | マーケット（指数・為替・金利・商品、セクター騰落、ヒートマップ） |
| `News.dc.html` | ニュース（3ペイン） |
| `Records.dc.html` | 記録（売買・配当） |
| `Settings.dc.html` | 設定・LAN同期 |
| `TopPicks.dc.html` | トップピック |
| `Memos.dc.html` | 銘柄メモ |
| `TopBar.dc.html` / `SideNav.dc.html` / `Ticker.dc.html` | 共通部品（上部バー、左ナビ、指数ティッカー＋ステータスバー） |

## デザイントークン（全画面共通）

| 用途 | 値 |
| --- | --- |
| 地の色 | `#0b0f14` |
| パネル | `#11161d`、見出し・表ヘッダー `#161c25`、グループ行 `#141a22` |
| 枠線 | `#232b36`、行の区切り `#1b222c`、入力欄の枠 `#2c3644` |
| 文字 | 本文 `#d8dee7`、補助 `#9aa6b6`（暗い背景でも 4.5:1 を満たす） |
| リンク | `#7fb3ff` |
| 強調色（選択中のナビ・タブ・主要ボタン） | `#f0a33a`、選択背景 `#2a2214`、選択文字 `#f5b955` |
| 選択行の背景 | `#1a2638` |
| 騰落色・日本式（既定） | 上昇 `#ff5c5c`、下落 `#4ea2ff` |
| 騰落色・米国式 | 上昇 `#2fc677`、下落 `#ff5c5c` |
| 文字 | `Inter`（英数字）＋ `Noto Sans JP`、本文 12px、数値は `font-variant-numeric: tabular-nums` で右寄せ |
| 行の高さ | コンパクト 24px（既定）／標準 32px |
| 余白 | ペイン間 4px、パネル内 8〜12px、角丸 4px |
