# Portfolio Manager 改修方針（要約）

## 目的
- カード中心の画面を、MarketSpeed II のような高密度の「作業用」画面に作り替える（トレード・発注機能は作らない）。
- 同じLAN内のPC同士を Link し、ボタン操作で SQLite を同期できるようにする。
- 銘柄に紐づくメモと、保有・ウォッチリストとは別の「トップピック」を追加する。

## フェーズ
0. 土台の整理：sqlite.ts とウォッチリスト画面の分割、セクター定義の統一、user_version によるマイグレーション管理、計算ロジックの切り出しとテスト、ドキュメント更新
1. LAN同期：論理削除（deleted_at）と updated_at、同期用テーブル（sync_meta / sync_peers / sync_log）、同期API、Link と同期ボタンのUI
2. 画面フレームと密度：左ナビ・画面タブ・分割ペイン・下部ティッカー・ステータスバー、保有銘柄テーブルの多列化、騰落色の切替
3. 新しい画面：銘柄詳細（ローソク足）、マーケット、登録銘柄の多列化、ニュース3ペイン、売買記録と保有の連動、銘柄メモ、トップピック
4. 仕上げ：mDNS による相手PCの自動検出、自動更新、同期ログ画面

## 決定事項
- セクターは `src/lib/sectors.ts` の `SectorKey`（GICS 11 + etf + other）に保有・ウォッチリストとも統一する。現金とFXはセクターではなく市場・シンボルから判定する。
- 価格マップのキーは `symbol|market`。
- 価格が取れない銘柄は「価格未取得」と表示し、取得単価で代用して損益0と見せない。
- DB のマイグレーションは `PRAGMA user_version` で番号管理する。
- 同期の競合は行単位の後勝ち（updated_at、同時刻はデバイスIDで決定）。
