## 判断したこと

- CSS は指示書の例に合わせ、`:not(.tv-lightweight-charts table)` でチャート配下のテーブルを除外した。既存の一覧テーブルのセレクタ対象は変わらない。
- `table tbody tr` 側は高さではなくホバー用 transition のルールだが、指示に従い同様に除外した。
- 検索欄は候補確定時に `setQuery('')` と `setIndex(0)` を行い、候補リストは `open` を false にして閉じる。`expanded` は空文字だと false になるため、リストは表示されない。

## 未対応・相談事項

- `npm test` の失敗は、作業開始時点で未コミットだった他タスクの変更（`src/lib/market.ts` に `group` を追加、`src/types/index.ts` の型追加など）によるもので、T15b の変更範囲外のため修正していない。`market.ts` の実装か `market.test.ts` の期待値のどちらかを別タスクで揃える必要がある。
