# T25 アプリアイコンの刷新

## 実施内容・デザイン

濃紺の角丸スクエアに、日本式の赤い陽線・青い陰線とアンバーの上昇線を組み合わせたアイコンに刷新した。文字・通貨記号は入れていない。

- マスターは512基準。背景は `#11161d` → `#0b0f14` の縦グラデーション、縁は `#232b36` の1px、角丸半径は112px（約22%）。
- ローソク足はヒゲ付き4本（陽線3本 `#ff5c5c`、陰線1本 `#4ea2ff`）。途中の下落を挟みつつ全体として切り上がる配置にした。
- 折れ線は `#f0a33a` の16px幅。暗い下地の線を重ねてローソク足との境界を保ち、右上の終点に小さな丸点を置いた。
- 16・24・32pxは3本（陽線2本・陰線1本）、ヒゲなしの簡略版から描画する。20pxで表示される上部バーのロゴとSVG faviconも、この簡略版を使用する。

### サイズ別の目視所感

OSの一時ディレクトリへPNGを書き出し、以下の4サイズを実寸で確認した。ICO内の同サイズの画素も上記のとおり照合済み。

| サイズ | 所感 |
| --- | --- |
| 16px | 3本の赤・青とアンバーの上昇線を区別できる。ヒゲを省くことで線同士のつぶれを抑えた。終点は小さな明点として見える。 |
| 32px | 3本の間隔、折れ線の折り返し、終点の丸点を認識できる。濃紺の地と縁も判別できる。 |
| 256px | 4本の実体と上下のヒゲが明瞭。アンバー線との境界が保たれ、右肩上がりの印象が伝わる。 |
| 512px | グラデーションと角丸が滑らか。線の太さ・丸点・ローソク足の余白が十分で、指定色のまとまりも確認できる。 |

## 判断したこと

- ビットマップ生成AIは使用せず、指定色と小サイズの可読性を制御できるSVGを直接作成した。
- 上部バーは20pxと小さいため、マスターと同じ配色・上昇線の意匠を持つ簡略版をロゴに採用した。
- ICOは各サイズのSVG描画結果を個別に渡して生成し、大きいPNGからの一律縮小を避けた。
- 依存インストール時の標準npmキャッシュは書き込み権限エラーになったため、OSの一時ディレクトリのキャッシュを指定して再実行し成功した。インストールスクリプトは実行していない。
