# T08c 実施レポート

実施日: 2026-10-23

## 実装結果

Next.js 16 で `next dev` の既定が Turbopack になり、`next.config.ts` の `webpack` 設定と衝突して `npm run dev` がページ配信前に終了していた。`package.json` の `scripts.dev` に `--webpack` を追加し、`build` と同じ webpack 経由で起動するようにした。これにより `npm run dev` と、それを呼ぶ `npm run desktop`（`electron/desktop-runner.mjs`）が起動できるようになる。

確認は `SQLITE_DB_PATH` に一時フォルダの空DBパスを設定した状態で行い、実ユーザーの `data/portfolio.db` は開いていない。

## 変更ファイル

| ファイル | 変更内容 |
| --- | --- |
| `package.json` | `"dev": "next dev"` を `"dev": "next dev --webpack"` に変更（1行のみ）。 |
| `docs/renovation/reports/T08c.md` | 本レポート。 |

## 確認結果

| コマンド・確認 | 結果 |
| --- | --- |
| `npx tsc --noEmit` | 成功、終了コード0、出力なし。 |
| `npm run lint` | 成功、終了コード0、指摘なし。 |
| `$env:SQLITE_DB_PATH`＝一時パスで `npm run dev -- -p 3012 --hostname 127.0.0.1` | 起動成功。`▲ Next.js 16.1.6 (webpack)`、`Ready in 1319ms`。 |
| `GET http://127.0.0.1:3012/` | 200。`GET / 200 in 2.7s (compile: 2.5s, render: 142ms)`、サーバーログにエラーなし。 |
| 確認後の停止 | `taskkill /T /F` でプロセスツリーを停止。ポート3012の待受は残っていない。 |
| 一時DBの状態（追加確認） | 同じ設定で `GET /api/portfolio-data` も実行し 200。一時フォルダに `portfolio.db`（4096バイト）が生成され、実DB `data/portfolio.db` の更新日時は確認前後とも 2026-10-22 23:32:29 で変化なし。`SQLITE_DB_PATH` の一時パスが使われていることを確認した。 |

## 判断したこと

- 指示書どおり `scripts.dev` の1行だけを変更し、`build`・`desktop` 系スクリプトや `next.config.ts` には触れていない。
- 確認用の開発サーバーは一時フォルダのDBパスを `SQLITE_DB_PATH` に設定してから起動し、確認後にプロセスツリーごと停止した。一時ファイルは `%TEMP%` 配下に作成した。
- 起動ログに `Environments: .env.local` と出るが、`.env.local` の `SQLITE_DB_PATH=data/portfolio.db` よりプロセス環境変数が優先されることを、一時DBが生成され実DBが変化しないことで確認した。
