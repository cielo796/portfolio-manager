# T22 トップピック追加ダイアログ：現在値の自動取得と選定日の初期値

## 変更したファイル

- `src/components/top-picks/add-pick-dialog.tsx`
  - 選定日（`pickedAt`）の初期値を Asia/Tokyo の今日（`YYYY-MM-DD`）にし、入力欄にも反映するよう `value` を追加。
  - 銘柄候補の選択時、銘柄コード欄の blur 時、市場の手動切り替え時に `POST /api/prices` を1銘柄分呼び、現在値を取得・保存するようにした。取得結果は `priceKey(symbol, market)` で照合し、銘柄・市場が変わった古い結果は表示しない。
  - 取得できたら「選定時の価格」の placeholder を `現在値 ¥xxx（空欄なら この値で記録）`／`現在値 $xxx（空欄なら この値で記録）` に変更。入力欄の値は自動で埋めない。
  - 取得中は追加ボタンを無効化せず、送信時に進行中の取得を待ってから作成APIへ送る。取得失敗時は何も表示せず、従来どおり作成APIの「現在値がありません。選定時の価格を入力してください。」に任せる。
  - 同時実行時は最新のリクエストIDだけを採用し、古い応答で placeholder が上書きされないようにした。
- `docs/renovation/reports/T22.md`（本ファイル）

`shared.ts` とサーバー側（`/api/prices`・作成API）は変更していない。

## 判断したこと

- placeholder は取得した `StockPrice.currency` が `JPY` なら `¥`、それ以外は `$` を付け、既存の `priceText` と同じ `ja-JP` の小数4桁までで表示した。
- 同じ銘柄・市場の現在値を取得済みの場合は blur 時の再取得をスキップし、追加ボタン押下時の待ち時間を増やさないようにした。
- 取得中表示は「現在値を取得中…」とし、銘柄・市場が一致するリクエストの間だけ表示する。
- 取得失敗は握りつぶし、手入力の妨げにしない（指示書の「現状どおりのエラー表示」に合わせる）。
