## 判断したこと

- `scripts/node-readlink-eisdir-fix.cjs` は Node の `--require` で読み込む CommonJS のため、`require()` はそのまま残し、lint 設定側のみでルールを無効化した。
- 追加した設定オブジェクトには、意図が分かるよう日本語の1行コメントを付けた。
- 対象を `**/*.cjs` に限定したため、`.ts` / `.js` など他のファイルの `require()` に関するルールは従来どおり有効。
