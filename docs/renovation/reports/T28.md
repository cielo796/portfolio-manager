## 判断したこと

- 価格更新のリクエストは保有画面の `refreshPrices` と同じ構成にした。保有が1件以上あるときは USDJPY（FX）も送信し、円換算レートと米国株の換算が同日に更新されるようにした。
- 価格APIが失敗してもスナップショットの読み直しは行うため、価格取得部分だけを `try/catch` で囲み、再読込はその外に置いた。
- 設定画面の「Symbol」は他画面に合わせて「ティッカー」、「Market」は「市場」とした。市場の選択肢 `US` / `JP` / `FX` はコードとして扱い、そのままにした。
- `Portfolio Manager v0.1.0` と `DBファイル: data/portfolio.db` のパス、サンプルプレースホルダー（`Apple / Toyota` など）は指示どおり／固有名詞の例として残した。
